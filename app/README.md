# Original World Cup 2026 match explorer

The public results archive is served from `public/index.html`. It lists verified final scores and venue-local match dates for all 104 matches.

`app/worldcup26/` preserves the original match explorer and its ESPN results snapshot in `data/results.json`.

The public archive was checked against ESPN’s dated scoreboards (for example, the [July 19 final](https://site.api.espn.com/apis/site/v2/sports/soccer/fifa.world/scoreboard?dates=20260719)).
